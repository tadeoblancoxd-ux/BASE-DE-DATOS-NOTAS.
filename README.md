# BASE-DE-DATOS-NOTAS.

plicación web para organizar y realizar un seguimiento de tareas y actividades.

📥 Descargar el proyecto
Entrar al repositorio de GitHub.
Hacer clic en Code.
Seleccionar Download ZIP.
Extraer el archivo ZIP en una carpeta.
▶️ Ejecutar el proyecto

Para ejecutarlo correctamente, es necesario tener instalado Node.js.

Abrir una terminal dentro de la carpeta del proyecto y ejecutar:

npx serve .

Cuando aparezca algo como:

Local: http://localhost:3000

abrir esa dirección en el navegador:

http://localhost:3000

🔐 Inicio de sesión

La aplicación utiliza Supabase para gestionar las cuentas de usuario y guardar los datos.

Cada usuario debe utilizar su propia cuenta.

💾 Datos

Las tareas y los datos del usuario se guardan en la base de datos de Supabase, por lo que no dependen únicamente del navegador o de la computadora donde se ejecuta la aplicación.
